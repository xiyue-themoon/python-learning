## 一、先认识一下 —— 你身边到处都是 AI

你可能没注意到，但 AI 已经在你生活里了：

- 刷抖音/小红书，推荐页越刷越懂你 → **推荐算法**
- 拍照时手机自动识别人脸、优化背景 → **计算机视觉**
- 输入法自动联想下一句，越用越准 → **语言模型**
- 百度搜东西，搜索引擎理解你想找什么 → **语义理解**

它们一直在你身边，只是藏在 App 里，你看不到。

但这两年有一类新 AI 走到了台前——**你直接跟它说话，它直接帮你做事**。这就是我们这里要聊的。

## 三、用 AI 做点实在的事

你不用学"怎么用 AI"，你只需要**想清楚你想干嘛**，然后把事情告诉它。这里列一些高一同学最容易用上的场景：

### 📚 学习帮手

```
你： 我高一，刚学到函数定义域。给我出 3 道题，从简单到难，
     每道题写完整解答过程。
DeepSeek：（出题 + 解析）
你： 第二题没看懂，为什么 x≠2？用更简单的话解释。
DeepSeek：（换种方式再讲一遍）
```

→ 你可以一直追问到彻底搞懂，不用怕问烦老师。

```
你： 帮我批改这篇议论文《论坚持》，600 字左右。
     标出：①论点是否清晰 ②论据是否支撑论点 ③语言表达问题。
     最后给总体评分和改进建议。
```

→ 贴进去它就能批。改完再让它评一次，看到进步。

```
你： 快期末了，复习中国近代史。把我下面的课堂笔记整理成
     时间线格式，标出每个事件的关键人物和影响。
     [贴上你的笔记]
```

→ 零散的课堂笔记扔进去，出来一张复习时间线。

### 🎨 创意工坊

```
你： 帮我写一个校园题材的短篇小说大纲，主角是一个高一的
     转学生，风格轻松治愈，出 3 个不同的情节走向。
```

→ 写故事开不了头？让 AI 给你第一块砖。

```
你（在可灵 AI 上）：
    "一只穿校服的猫在写作业，窗外是晚霞"
```

→ 输入文字，直接生成图片。你描述什么，它画什么。

### 🛠️ 效率工具

```
你： 帮我做一份班级秋游计划，30 个人，预算人均 200，
     地点在市区，包含交通方案、活动安排和物品清单。
```

→ 不用从空白文档开始，AI 给你骨架，你改改就能用。

```
你： 帮我分析这份成绩单，找出每科的趋势——哪些在进步、
     哪些在退步，给出针对性建议。
```

→ 贴表格进去，AI 帮你读数据。

## 五、跟 AI 相处的三个心法

### 1. 它很聪明，但它也会胡说

AI 像一个读过整个互联网但没真正活过的实习生——能写出漂亮的句子，但不知道自己在说什么。

- 它"自信地胡说"不是 bug，是它的**出厂设置**
- 事实性的东西**要验证**（搜一下、问一下老师）
- 创意性、脑暴类的东西尽管让它发挥

**简单判断：** 问事实 → 保持怀疑；问创意 → 尽管放开。

### 2. 信息给得越具体，它答得越好

```
❌ "帮我写作文"           → 给你一篇你可能用不上的
✅ "写议论文，主题坚持，   → 直接能用
   800字，高一水平，
   要正反论证"
```

差别不是 AI 变了，是你把条件说清楚了。

### 3. 不满意就让它再来一次

这是 AI 和搜索引擎最大的区别——你可以**反复追问**：

- "再简单一点"
- "换一个比喻"
- "举一个高中生的例子"
- "你确定吗？从哪里知道的？"

如果你觉得 AI 有意思，想学更多，这里是最低门槛的入口：

### 🐣 纯好奇，随便看看
