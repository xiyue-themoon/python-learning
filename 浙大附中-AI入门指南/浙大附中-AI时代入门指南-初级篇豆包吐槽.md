## — 初级篇 · 对话 AI

### 选哪个？

市面上免费的对话 AI 不少，但作为入门，你其实只需要在三个里面选一个：

**DeepSeek** — 综合能力最强，完全免费不限次数。中文理解在国产里属于第一梯队。如果你只装一个，装它。

**Kimi** — 长文档处理之王。能一次读 200 万字（≈ 整套《三体》）。适合丢论文、合同、整本教材进去让它总结。

**豆包** — 字节出品，语音对话最方便，不想打字可以直接说。

不过说到豆包，有个江湖传说值得一听。

2025 年，有人发现豆包内置的代码执行环境（一个给用户跑 Python 的沙盒）能做一件很离谱的事：**你可以在这个沙盒里装 SSH 服务端、开 frp 隧道、从外网连进去，得到一个完整的 2 核服务器。** 等于字节跳动免费送你一台云主机。

具体的操作流程被完整发在了 GitHub 上，标题叫 "DouBaoVPS-Exploit"——注意，是 **Exploit**，不是 "How to use"。流程之丝滑，以至于项目说明里甚至贴心地写了"图一乐就行，长时间不对话它会断"。

这件事真正有意思的地方不是"有人发现了漏洞"——哪个大厂没出过安全事件？真正有意思的是它的**运营策略**：一边把内容审核做得草木皆兵，日常对话里问个稍微敏感点的问题就被"我还没学会回答这个问题"糊脸；一边又把代码执行环境的沙盒做得跟纸糊的一样，让人直接拿它当免费 VPS 用。

重内容安全，轻架构安全——这种策略选择本身就说明了很多问题。

当然，这个洞已经被补上了。你想体验的话现在也体验不了了（除非你本来就是想用一个对话 AI 聊天，那你不受影响）。只是当你以后在别的平台上看到类似"安全可靠"的承诺时，记住这个故事。

> 借用项目 README 里那句经典名言收尾：
> "毕竟你为了这个买个 VPS 也就不需要折腾豆包了。"

（言下之意：你得先有自己的服务器才能白嫖豆包的服务器。这矛盾本身就挺幽默的。）
