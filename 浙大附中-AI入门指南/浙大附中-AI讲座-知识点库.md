## 1. AI 发展史关键节点

> 环节一「AI 前世今生」的史实骨架。事件 + 年份 + 一句话技术意义。
> 来源：待补充。

### 1.1 图灵测试 (1950)

**事件概述：** 艾伦·图灵于1950年10月在论文《计算机器与智能》中提出"模仿游戏"。测试者通过文本与一人一机对话，若无法区分二者，则机器被认为具有智能。

**技术意义：** 首个关于机器智能的严肃哲学与操作性定义，奠定了AI的终极评判框架。

**关键事实：** 图灵预测到2000年，机器能在5分钟对话中骗过30%的测试者。

### 1.2 深蓝 vs 卡斯帕罗夫 (1997)

**事件概述：** 1997年5月，IBM的并行计算机"深蓝"在纽约六局对抗赛中，以3.5:2.5击败国际象棋世界冠军加里·卡斯帕罗夫。

**技术意义：** 首次在标准时限的国际象棋比赛中战胜 reigning 世界冠军，证明暴力搜索+手工评估在封闭博弈中的有效性。

**关键事实：** 32节点IBM RS/6000 SP，256颗定制象棋处理器；运算速度每秒2亿步；计算能力11.38 GFLOPS。

### 1.3 AlexNet / 深度学习复兴 (2012)

**事件概述：** 多伦多大学Alex Krizhevsky等人提出AlexNet，在ILSVRC-2012中以Top-5错误率15.3%夺冠，较第二名低10.8个百分点。

**技术意义：** 深度学习复兴的标志性事件，证明了深度卷积网络+GPU+大规模数据三要素的有效性。

**关键事实：** 8层网络（5卷积+3全连接），6000万参数，65万神经元；在双GTX 580 GPU上训练5-6天；使用ReLU、Dropout（0.5）和数据增强。

### 1.4 AlphaGo vs 李世石 (2016)

**事件概述：** 2016年3月，DeepMind的AlphaGo在首尔以4:1击败韩国棋手李世石九段。

**技术意义：** 首次在围棋（搜索空间10^170）中击败顶级人类职业棋手，验证了深度强化学习+蒙特卡洛树搜索的可行性。

**关键事实：** 技术方案为策略网络+价值网络+蒙特卡洛树搜索（MCTS）。第四局第78手"挖"被称作"神之一手"，导致AlphaGo后续出现异常走子并最终认输。

### 1.5 Transformer 架构 (2017)

**事件概述：** 2017年6月12日，Google Brain八位作者在arXiv发表《Attention Is All You Need》，提出完全基于自注意力机制的Transformer架构。

**技术意义：** 完全摒弃RNN和CNN，实现序列建模的并行化，成为GPT、BERT、DALL-E等所有后续大模型的基础架构。

**关键事实：** 编码器和解码器各6层，多头注意力（8 heads）；WMT 2014英德翻译28.4 BLEU；截至2025年6月被引超18万次。

### 1.6 GPT-3 (2020)

**事件概述：** OpenAI发布GPT-3（Language Models are Few-Shot Learners），参数量达1750亿。

**技术意义：** 首次证明超大规模语言模型通过In-Context Learning即可在少样本/零样本下完成广泛任务，无需参数更新。

**关键事实：** 训练数据包括经过过滤的CommonCrawl、WebText2、Books1/2和Wikipedia；上下文窗口2048 token；训练了从1.25亿到1750亿的多个规模模型。

### 1.7 ChatGPT 发布 (2022)

**事件概述：** 2022年11月30日，OpenAI发布ChatGPT，基于GPT-3.5架构，采用RLHF（人类反馈强化学习）进行指令对齐。

**技术意义：** 将大语言模型的能力以对话交互形式直接呈现给大众，成为AI技术进入主流社会的分水岭。

**关键事实：** 上线5天用户破100万，2个月月活用户破亿；为史上增长最快的消费级应用。

### 1.8 GPT-4 至当前 (2023–2026)

**事件概述：** 2023年3月14日OpenAI发布GPT-4，支持图像与文本的多模态输入。随后Agent风潮兴起，Scaling Law面临挑战。

**技术意义：** 多模态能力扩展了LLM的感知边界；Agent范式将LLM从"对话工具"提升为"行动主体"；Scaling Law遭遇收益递减，推动行业从"更大"转向"更高效"。

**关键事实：** OpenAI未公布GPT-4的具体参数量、架构和训练细节。

## 2. 当前 AI 能力地图

> 环节二「AI 现在的版图」的素材。每个方向：事实概况 + 能力边界 + 一个贴近高一的具体例子。
> 来源：DeepSeek 网页版，2026-07-15。

### 2.1 语言模型（LLM）

**事实概况：** 基于 Transformer Decoder-only 架构、自回归 next-token prediction 的概率语言模型。训练目标为最大化序列似然，推理时通过采样/束搜索生成文本。当前主流代表：GPT-4、Claude、DeepSeek、Gemini、Qwen。

**能力边界：**
- 能：文本摘要、翻译、代码补全、结构化问答、多步逻辑推理（如数学应用题）
- 能：处理长上下文（128k–1M tokens）内的信息检索与整合
- 不能：保证输出事实准确性，无外部知识实时验证时会产生幻觉
- 不能：具备真正的语义理解或意识，输出本质为基于统计模式的条件概率采样

**案例：** 高一学生用 DeepSeek 输入"请批改我的议论文《论坚持》，标出论点与论据是否匹配，并给出修改建议"。

### 2.2 视觉模型

**事实概况：** 基于 Vision Transformer（ViT）或 CNN 作为主干网络，将图像编码为特征向量后接入语言模型或分类头，实现视觉理解。当前代表：GPT-4V、Gemini Vision、Qwen-VL、Claude 3.5 Sonnet（视觉版）。

**能力边界：**
- 能：图像分类（物体/场景）、目标检测（框出物体）、OCR（印刷体/手写体识别）、视觉问答
- 能：多图对比与简单图表解读（折线图趋势、柱状图数值）
- 不能：精细空间关系推理（如判断两条线段是否严格平行），对抗噪声下准确率大幅下降
- 不能：产生"物体幻觉"（将噪声误识别为不存在对象），对遮挡、翻转敏感

**案例：** 高一学生用手机拍摄校园植物叶片，Qwen-VL 识别为樟树并输出"叶脉为离基三出脉，区别于桂花叶"。

### 2.3 生成模型

**事实概况：** 基于扩散模型（Denoising Diffusion Probabilistic Model，从高斯噪声迭代去噪）或自回归 Transformer（逐 token 生成像素/音频码流）。代表：图像——Stable Diffusion 3.5、Midjourney v6、DALL-E 3；视频——Sora、Runway Gen-3；音频——Suno、ElevenLabs。

**能力边界：**
- 能：根据文本提示生成 1024×1024 以上分辨率图像、4–60 秒短视频、多声部音乐及语音克隆
- 能：进行图生图（风格迁移、局部重绘）和视频帧插值
- 不能：保持物理规律一致性（如水流动方向、物体碰撞变形），生成细节（手指数量、文字拼写）常出错
- 不能：产生真正的"创意"，输出本质为训练数据分布的高维插值组合

**案例：** 高一班级用 Suno 输入"青春、奔跑、毕业季，流行摇滚风格"，生成 2 分钟班歌 demo，用于运动会入场式。

### 2.4 Agent 系统

**事实概况：** 以 LLM 为核心调度器，采用 ReAct 范式（Reasoning–Acting–Observing）循环：推理当前状态 → 调用外部工具 → 观察返回结果 → 更新记忆并规划下一步。框架包含工具库、短期记忆缓冲区和长期向量记忆。

**能力边界：**
- 能：自主完成多步信息检索（如"查近三天天气→结合课表推荐穿衣"）
- 能：执行代码自动生成与运行（调用 Python 解释器解微积分方程）
- 不能：处理需要毫秒级精确时序控制的物理操作，因推理延迟高且执行失败无回滚
- 不能：保证长周期任务（超过 10 步）稳定执行，单步错误会级联放大，且缺乏跨会话的持久长期记忆

**案例：** 高一学生设置 Agent 自动执行：读取钉钉课表 API → 查询当地天气 API → 扫描班级群作业截图（OCR）→ 生成每日"课程+天气+作业优先级"学习计划 Excel。

## 3. AI 固有限局限汇编

> 环节三「你该怎么跟它相处」的素材。从 §C 概念库精确定义加工成讲座可引用的精确表述。
> 来源：情报库 §C AI核心概念精确定义 + 知识点库 Block 2 能力边界。

### 3.1 幻觉（Hallucination）

**技术事实：** LLM 基于条件概率分布生成"可能且内部连贯"的续写，缺乏将输出约束为与真实世界对应的内置机制。Softmax 将潜在模糊的注意力分数坍缩为单一概率分布，产生"人工确定性"——模型自信地给出错误答案。幻觉存在与训练数据量、语言复杂性和生成方式相关的理论下界，无法通过优化彻底消除。

**讲座可用转述方向：**
- AI 像一个读过整个互联网但没真正活过的实习生——能写出漂亮的句子，但不知道自己在说什么
- 它"自信地胡说"不是 bug，是架构特性：你问它一个它不知道的事，它不会说"不知道"，它会编一个看起来合理的答案
- 这意味着：**你需要对 AI 的输出保持批判态度**，尤其是涉及事实的场合

### 3.2 无真实理解

**技术事实：** LLM 的本质是基于统计模式的条件概率采样器。它的训练目标是最大化下一个 Token 的预测准确率，而非理解文本的语义含义。输出在语法和局部连贯性上具备表面合理性，但模型内部不存在语义表征——语言学家 Emily Bender 将这种现象称为"随机鹦鹉"（Stochastic Parrot）。

**讲座可用转述方向：**
- AI 不"理解"它写的东西——它只是从海量文本中学会了"出现这个词之后大概率出现那个词"
- 就像一个没学过中文的人背下了整本成语词典，能正确使用每个词，但不知道它们的意思
- 这解释了为什么 AI 能写出漂亮的作文，但会被简单的逻辑陷阱绕进去

### 3.3 上下文遗忘

**技术事实：** Transformer 自注意力的 O(n²) 复杂度决定了上下文窗口存在硬上限。RoPE 位置编码使远端 Token 的注意力权重在对角线附近最密集——模型并非均匀关注窗口内所有内容，远端信息的有效利用率随距离衰减。即使窗口扩大到 128K–1M，远端信息在实际使用中仍存在注意力权重稀释的问题。

**讲座可用转述方向：**
- AI 有一个"短期记忆上限"——你让它读了一篇长文章，问到最后一段的问题时它可能已经忘了开头说了什么
- 这和人一样：让你一次读完一本 500 页的书然后随机提问，你也会忘
- 但区别是：人知道"我忘了"，AI 不知道自己忘了，它会假装还记得然后乱答
- 处理长文档时，最好的策略是把问题拆小、分次问

### 3.4 无真实世界体验

**技术事实：** LLM 的训练数据为静态文本语料，模型从未接触过物理世界中的感官输入（视觉、触觉、空间感知、因果关系体验）。它通过文本描述"知道"苹果是红色的、甜的、从树上掉下来，但不存在任何对应的感知经验。这意味着它无法理解任何需要具身认知才能掌握的概念——比如"推一个物体的感觉""物体碰撞的物理反馈"。

**讲座可用转述方向：**
- AI 知道"苹果是甜的"是因为上亿人写过这句话，不是因为它吃过苹果
- 它写"雨后空气清新"是因为语料里这句话出现了几万次，不是因为它真的闻过雨后的空气
- 这解释了为什么 AI 在物理常识问题上常犯错——你让它判断一杯水倒过来会怎样，它能回答对，因为语料里有；但你问一个语料里没有的物理情境，它就不知道了

## 5. 破障学科精简版

> 如果高一学生想认真进入 AI 领域，需要突破哪些学科障碍。
> 来源：DeepSeek 网页版，2026-07-15。

### 5.1 编程

**核心事实：** Python 凭借简洁语法、完善的科学计算生态（NumPy、PyTorch 等）及作为 C++/CUDA 后端胶水层的特性，在 AI 研究、实验和部署中占据主导地位。

**要点：**
- Python 实际地位：99% 以上 AI 顶会论文开源代码以 Python 编写；C++/Java 负责底层推理引擎和移动端部署，Python 作为前端接口实现模型训练、调参和实验迭代。
- 最低知识边界：变量（int/float/str/bool）、列表与字典的索引/切片/增删改查、`if-elif-else` 和 `for/while` 循环、自定义函数（参数、返回值）、类的基本定义（`__init__` 和方法调用）、异常处理（`try/except`），以及至少掌握一个 ML 库的加载与推理链：`import torch`、`model = AutoModel.from_pretrained(...)`、`tokenizer(...)`、`outputs = model.generate(...)`。
- 时间区间：每日30分钟投入，约4–6个月；每日2小时投入，约2–3个月。

### 5.2 思维训练

**核心事实：** 高中阶段的数学、物理、化学等学科培养的抽象建模和逻辑演绎能力，与 AI 中的问题形式化和算法设计具有相同认知结构。

**要点：**
- 数学实际作用：
  - 线性代数：向量与矩阵的乘法、转置、维度变换，对应神经网络中的张量运算和全连接层权重乘法。
  - 概率论：条件概率、贝叶斯定理、期望与方差，对应语言模型中的 next-token 概率分布及生成采样（top-p）。
  - 微积分：导数、偏导数、梯度和链式法则，对应反向传播算法和梯度下降（SGD/Adam）的数学原理。
- 物理/化学对拆解问题的训练：物理受力分析、运动学方程，化学速率方程、平衡常数计算——均是将复杂现象抽象为可控变量并建立数学方程求解的过程，与 AI 中将自然语言或视觉任务转化为损失函数最小化问题的形式化方法共通。
- 信息竞赛/编程社团的实际价值：提供严格的时间和空间复杂度训练，强化调试、数据预处理及代码工程化能力，同时提供多人协作和版本管理的真实项目经验。

### 5.3 英语

**核心事实：** AI 顶级研究以英语为首发语言，但现有翻译工具可将全英文资料的阅读门槛降至接近零，中文解读社区同步提供学术热点。

**要点：**
- 真实需求分级：入门级（仅需中文资料即可）/ 进阶级（需阅读英文论文标题和摘要以跟踪 SOTA）/ 研究级（需全文阅读英文论文并参与国际社区讨论）。
- 降门槛工具：浏览器内置网页翻译、沉浸式翻译插件（双语对照）、AI 翻译（DeepL、DeepSeek 翻译）、中文社区（CSDN、知乎专栏）。
- 国内可访问的英文 AI 论文中文解读平台：机器之心（jiqizhixin.com）、量子位（qbitai.com）、PaperWeekly（paperweekly.cn）、AMiner 中文解读（aminer.cn）。
