# 南湖革命纪念馆 · 讲解稿 Prompt 模板库

> 用法：复制对应 prompt → 粘贴到 DeepSeek 网页版 → 替换 `[括号]` 内容 → 得到稿子
> 组员拿到稿子读一遍录像，每人负责 1-2 段

---

## 模板 A：核心文物（单件 · 30-45秒 · 200-300字）

### A-1 通用模板

```
你是一位有温度的博物馆讲解员，请为[南湖革命纪念馆]的[文物名称]写一段讲解词。

要求：
1. 开头从实物细节出发（"你看这件……"），让人有在场感
2. 中间讲一段与这件文物相关的真实历史故事，有具体人物和情节
3. 结尾用"今天再看……"自然收束，点出精神传承，不喊口号
4. 总字数 240-280 字，读出来约 35-40 秒
5. 语气像在跟朋友聊天，不要念稿感
```

### A-2 填充好的具体文物（到现场直接取用）

**① 红船模型（核心中的核心）**

```
你是一位有温度的博物馆讲解员，请为南湖革命纪念馆的"红船模型"写一段讲解词。

要求：
1. 开头描述这艘船的实物细节（尺寸、颜色、它在展厅中的位置）
2. 中间讲1921年8月初，中共一大代表从上海转移到嘉兴南湖的经过——
   具体讲王会悟如何安排、代表们如何装作游客、在船上如何开会
3. 结尾用"今天再看这艘船……"自然收束
4. 总字数 260-280 字，读出来约 40 秒
5. 语气像在跟朋友聊天
```

## 模板 B：展区串词（整区 · 1.5-2分钟 · 500-700字）

### B-1 通用模板

```
你是一位有温度的博物馆讲解员，请为南湖革命纪念馆的[展区名称]展区写一段完整讲解词。

要求：
1. 开场说明这个展区的主题是什么（20字以内点题）
2. 中间串联 2-3 件该展区最有代表性的展品/场景，每件讲一个细节
3. 结尾用"走完这个展区，你会发现……"自然收束，点出这个展区想传达的核心信息
4. 总字数 550-650 字，读出来约 1.5-2 分钟
5. 语气像在跟朋友聊天，不要念稿感
6. 不用列"第一件/第二件"，用自然的过渡句串联
```

### B-2 填充好的具体展区

**① 序厅（开篇整体引入）**

```
你是一位有温度的博物馆讲解员，请为南湖革命纪念馆的"序厅"写一段整体开场讲解词。

要求：
1. 开场用一句话说清：嘉兴南湖为什么是中国共产党的诞生地之一
2. 用"你可能会好奇，为什么偏偏是南湖？"作为问题引子
3. 中间简要说明三个关键信息：
   - 1921年7月中共一大在上海开幕
   - 因法租界巡捕搜查被迫转移（具体：7月30日晚有人闯入）
   - 李达夫人王会悟建议转移到嘉兴南湖
4. 结尾用"走进这个展厅，你将看到……"自然引出后面的参观
5. 总字数 500-600 字，读出来约 1.5 分钟
6. 语气像在跟朋友聊天
```

**② 开天辟地展区**

```
你是一位有温度的博物馆讲解员，请为南湖革命纪念馆的"开天辟地"展区写一段完整讲解词。

   - 中共一大在上海的筹备过程
   - 南湖会议的历史意义
3. 讲一个具体细节：参会代表最年长的和最年轻的分别是？他们当时分别多大？
4. 结尾用"走完这个展区，你会发现……"自然收束
5. 总字数 550-650 字，读出来约 1.5-2 分钟
6. 语气像在跟朋友聊天
```

**③ 红船精神展区**

## 模板 C：串场过渡（从一个展区走到下一个 · 15-20秒）

```
你是一位有温度的博物馆讲解员，请写一段15秒的过渡词：
从"[上一个展区]"走向"[下一个展区]"，用一句话承上启下。
语气自然，像在跟朋友说"走，我们去那边看看"。
```

示例：从"开天辟地"走向"红船精神"
> "刚刚我们看到了那艘改变历史的红船模型，但你可能不知道——'红船精神'这个说法不是1921年就有了的。走，我们去前面看看它到底是什么时候提出的。"

## 拍摄速查

| 项目 | 标准 |
|:-----|:-----|
| 画幅 | 手机横屏 16:9（剪视频方便） |
| 收音 | 安静环境，嘴离手机 20-30cm，别太近（喷麦） |
| 灯光 | 脸朝向自然光/展柜灯光，背光=废片 |
| 读法 | **理解再讲不要背**——看稿2遍后脱稿讲，允许断句，允许看镜头 |
| 人均 | 每人 1-2 段，每段录 2-3 遍挑最好的 |
| 命名 | 文件名即标签：`展区名_组员名_01.mp4` |
