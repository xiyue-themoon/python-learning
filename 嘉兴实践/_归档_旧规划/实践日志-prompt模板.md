# 嘉兴红色实践 · 日志 Prompt 模板库

> 用法：复制对应日期的 prompt → 贴到 DeepSeek 网页版 → **AI 会先问问题，你回答完它再出稿**。你只需要回忆当天发生了什么、有什么感受，不用自己打框架。

---

## 📌 使用说明（给组员）

1. **把整段 prompt 复制到 DeepSeek 对话框**，按回车发出去
2. **AI 会先问你好几个问题**（天气、见到了什么、有什么感受等）——随便回答就行，一两句话一条
3. **所有问题答完后 AI 会自动生成一篇日志草稿**
4. **读一遍草稿，改成你自己的语气**——加你的口头禅、去掉不像你说的词
5. 搞定 ✅

> 💡 你不需要一次答完所有问题，DeepSeek 会一个一个来，你跟它聊天就行。

## Day 1 — 7/20（一）民国遗迹 + 侵华史迹 + 铁路博物馆

### 当日行程
民国辛亥革命纪念塔+墙 → 侵华日军炮楼遗址 → 嘉兴铁路博物馆

### Prompt 内容

```
你是一位会写大学生社会实践日志的 AI 助手。现在你要帮我写一篇 2026 年 7 月 20 日的实践日志。

【规则】
1. 你先问我 5-8 个关于今天的问题，一个一个问题来，不要一次性全抛
2. 我回答完所有问题后，你根据我的回答生成一篇完整的实践日志
3. 日志要求：
   - 字数 600-900 字
   - 语气像在写日记，自然、不喊口号
   - 包含具体场景描写和个人感受
   - 段落自然，不要用"首先其次最后"

【今天的背景】
- 社会实践主题：嘉兴红色基因传承
- 今天是第一天（7 月 20 日，星期一）
- 我们去了三个地方：
  ① 民国辛亥革命纪念塔和纪念墙
  ② 侵华日军炮楼遗址
  ③ 在其遗址上扩建的嘉兴铁路博物馆

现在先问我第一个问题吧。
```
