## §3.x 线性回归 & Softmax

### [3.1~3.2] 训练循环四步走
- 困惑：前向 → 算损失 → backward → 更新，每一步在干什么？
- 核心：
  ```
  ① 前向：    y_pred = X@W + b          ← 用当前参数做预测
  ② 算损失：  loss = (y_pred - y)^2      ← 预测和正确答案差多少
  ③ 反向：    loss.backward()            ← 框架自动算每个参数的梯度
  ④ 更新：    param -= lr * param.grad   ← 沿着梯度方向调参数
  ```

### [3.4] Softmax + 交叉熵损失
- 困惑：为什么分类不用平方误差，要用交叉熵？
- 核心：
  ```
  平方误差：关注所有类的分数都接近正确答案 → 对「接近 0 但不够高」的类也要惩罚 → 梯度小，学得慢
  交叉熵：只关注「正确答案的概率」→ log(p) 在 p 接近 0 时梯度巨大 → 学得快
  一句话：分类任务用交叉熵，回归任务用 MSE
  ```

### [3.5] 交叉熵数学
- 困惑：-∑ y·log(p) 这个公式在做什么？
- 核心：y 是 one-hot（正确类=1，其余=0），所以公式简化为 -log(p_正确类)
  ```
  正确类概率 0.9 → -log(0.9) ≈ 0.1  ← 小损失 ✓
  正确类概率 0.1 → -log(0.1) ≈ 2.3  ← 大损失，惩罚狠
  ```

## §4.1 MLP 概念

### [4.1] 为什么要非线性激活函数？
- 困惑：两层 Linear 叠两层 Linear，跟一层有什么区别？
- 核心：
  ```
  没有激活函数：y = (X@W1+b1)@W2+b2 = X@(W1@W2) + (b1@W2+b2) = 一层线性 → 废物
  有 ReLU：     负数砍掉 → 线性变换被打断 → 真正的非线性 → 能学复杂边界
  面试官类比：
    线性 = 只看加权总分
    非线性 = 每个维度独立评判，某个方面不及格直接一票否决
  ```

### [4.2] MLP 参数维度
- 困惑：W1 到底是 (784, 256) 还是 (256, 784)？
- 核心：
  ```
  记住：W 的形状 = (这一层的输入数, 这一层的输出数)
  输入 784 → 隐藏层 256  →  W1 = (784, 256)
  隐藏层 256 → 输出 10   →  W2 = (256, 10)
  验证：X(batch, 784) @ W1(784, 256) → (batch, 256) ✓
  ```

### [4.5] 正则化
- 困惑：这个专业名词忘了是什么意思
- 核心：防止过拟合的「工具包」
  ```
  权重衰减：loss += λ||w||²        ← 权重太大扣分
  Dropout：训练时随机丢神经元      ← 没人可依赖，每个神经元学更扎实
  简化模型：少几层/少几个神经元    ← 不够复杂就没法死记硬背
  加数据：n_train 变大             ← 覆盖更多真实分布
  ```

### [4.6] Dropout 缩放
- 困惑：为什么训练时 dropout 后要除以 (1-p)？
- 核心：
  ```
  训练时随机丢 p% 神经元 → 期望输出 = (1-p) × 全量输出
  测试时不丢 → 输出会变大 1/(1-p) 倍 → 所以训练时提前缩放到期望一致
  不是测试时「加回来」，是训练时提前除好了
  ```

## §6.2 卷积

### [6.2] 卷积核的工作方式
- 困惑（纠正过）：以为卷积是先预处理定位再识别，两阶段
- 核心：
  ```
  错误理解：卷积找区域 → 全连接层识别（两阶段）
  正确理解：卷积+全连接 = 端到端一次训练，所有参数一起反向传播更新
  卷积核不是手设计的，跟全连接层权重一样是学出来的
  ```

## §8 RNN（8.1-8.3 已闭合 8/20；8.4-8.7 已讲 8/20-8/21，§8 全部 7 节走完）

### [8.1] 序列为什么用条件概率建模 ✅ 已闭合（8/20 重讲）
- 核心（能独立讲清）：
  ```
  链式法则: P(x_1..x_T) = Π P(x_t | x_1..x_{t-1})
  两个近似: 自回归(固定窗口 τ) vs 隐变量(总结 h_t = g(h_{t-1}, x_{t-1}))
  h_t 就是 RNN 隐状态的前身 ← §8.4 的关键入口
  马尔可夫条件: 只看最近 τ 个 → τ=1 是一阶马尔可夫
  ```

### [8.2] token 化流程 ✅ 已闭合（8/20 重讲）
- 核心（能独立讲清）：
  ```
  四步: 加载字符串 → 词元化(token) → 建词表(vocabulary) → 转数字索引
  特殊词元: <unk> 未知词(索引0兜底) / <pad> 填充 / <bos>/<eos> 句首句尾
  单词分词词表上万 vs 字符分词词表~28 → 教材用字符
  ```

### [8.3] 语言模型 = 预测下一个词 ✅ 已闭合（8/20 重讲）
- 核心（能独立讲清）：
  ```
  语言模型目标: 估计 P(x_1..X_T) = Π P(x_t | 前文)
  统计法: P(learning|deep) = n(deep,learning)/n(deep)
  三个死穴: 组合爆炸 / 忽略语义 / 记不住远距离 → RNN 登场理由
  齐普夫定律: 词频 ∝ 1/i^α，长尾数不准 → 神经网络替代计数
  n-gram: unigram(0阶)/bigram(1阶)/trigram(2阶)
  ```

### [8.4] RNN 原理 ✅ 已讲（8/20）
- 核心：
  ```
  MLP:  H = φ(X·W_xh + b_h)
  RNN:  H_t = φ(X_t·W_xh + H_{t-1}·W_hh + b_h)   ← 只多 H_{t-1}·W_hh 一项
  隐藏层 vs 隐状态: 观测路径中间层 vs 技术角度历史压缩包
  参数共享: 不同时间步用同一组参数 → 参数量不随时间步增长
  拼接等价: X·W_xh + H·W_hh = concat(X,H)·concat(W_xh,W_hh)
  困惑度: exp(平均交叉熵) → 1=完美, 词表大小=瞎猜基线
  ```

### [8.5] 从零实现 ✅ 已温习（8/21 完整重走），验收留实践环节
- 8/21 完整重走：唤醒 → WHY(隐变量记忆) → 对比表(RNN vs MLP) → 形状推演 → 逐行代码 → 预测流程
- 温习要点（实践验收 = 手写 RNN 前向 + 形状推演）：
  ```
  5 参数: W_xh(vocab,h) W_hh(h,h) b_h(h) W_hq(h,vocab) b_q(vocab)
  独热: X(批量,时间步) → X.T one_hot → (时间步,批量,词表)  最外层=时间步
  循环: for X in inputs: H = tanh(X@W_xh + H@W_hh + b_h); Y = H@W_hq + b_q
  形状: 每步 H(批量,h) 不变；Y 每步(批量,vocab)；cat → (时间步×批量, vocab)
  预测: 预热期(只更新状态不输出) → 自生成(把上一步输出当输入, argmax)
  口诀: 最外层永远时间步；H 形状 (batch,h) 每步不变
  预热WHY: H_0=零向量无上下文，预热让状态吸收真实前缀语境后再开口生成
  ```

### [8.6] 简洁实现 ✅ 已讲（8/21）
- 核心（能独立讲清）：
  ```
  nn.RNN(len(vocab), num_hiddens) = 把 8.5 的 5 参数+tanh 循环封装成一行
  state 形状: (层数, batch, h) = (1, batch, h) 起步 ← 比手写多一层数维度(为多层RNN预留)
  坑: rnn_layer 的输出 Y 是每步隐状态 (T,batch,h)，不是预测分数！
     预测要自己接 nn.Linear(h, vocab) → reshape(-1,h) → (T×batch, vocab)
  分工: nn.RNN 只做「记忆」，Linear 做「预测」
  ```

### [8.7] BPTT ✅ 已讲（8/21）
- 核心（能独立讲清）：
  ```
  BPTT = 反向传播沿时间链应用；同一 W_hh 在 T 个时间步被用 T 次 → 梯度递归展开成连乘
  连乘 W_hh^T 高次幂: 特征值<1 → 梯度消失(远步传不回) / 特征值>1 → 梯度爆炸(训练发散)
  连乘类比: 复利。利率<0 滚到0，>0 滚到天文数字
  三种策略: 完全计算(不可行❌) / 截断τ步(实践默认✅,轻度正则化) / 随机截断(理论好实测不更好❌)
  8.5/8.6 训练切段(每段独立反传、段间梯度断) = 截断 BPTT 的隐形实现
  伏笔: GRU/LSTM(§9) = 给连乘开直通门，让信息跳过多次连乘 → 现代RNN核心动机
  ```

## §9 现代RNN（9.1/9.2 概念层 ✅ 8/22；9.3-9.8 待学）

### [9.1] GRU 门控循环单元 ✅ 概念层（8/22）
- 动机（能独立讲清）：
  ```
  RNN 无差别全量更新 H_t = φ(X_t·W_xh + H_{t-1}·W_hh + b_h) 治不了三个场景:
  ① 重要早期信息要长期保存 ② 无关词元要跳过 ③ 逻辑中断要重置
  GRU = 加两个可学习门，自己学会什么时候更新/重置/原样保留
  ```
- 核心公式（能独立写出）：
  ```
  R_t = σ(X_t·W_xr + H_{t-1}·W_hr + b_r)             重置门(reset gate): 过去状态在候选里值多少
  Z_t = σ(X_t·W_xz + H_{t-1}·W_hz + b_z)             更新门(update gate): 新旧状态混合比例
  H̃_t = tanh(X_t·W_xh + (R_t ⊙ H_{t-1})·W_hh + b_h)  候选隐状态(candidate)
  H_t = Z_t ⊙ H_{t-1} + (1-Z_t) ⊙ H̃_t                凸组合: Z→1 旧状态直通, Z→0 彻底翻新
  ```
- 梯度路径：Z→1 时 ∂H_t/∂H_{t-1} ≈ 1 → 信息跨步直通，绕过 W_hh 连乘（8.7 伏笔兑现）
- 参数量 ≈ RNN 的 3 倍（两门 + 候选各一套 W）

### [9.2] LSTM 长短期记忆 ✅ 概念层（8/22）
- 核心（能独立讲清）：
  ```
  灵感来自计算机逻辑门；1997 年提出（比 GRU 早 17 年）
  两条状态线: C_t 记忆元(memory cell)=长期账本 / H_t 隐状态=对外输出
  ```
- 核心公式（能独立写出）：
  ```
  I_t = σ(X_t·W_xi + H_{t-1}·W_hi + b_i)   输入门(input gate): 新候选收多少
  F_t = σ(X_t·W_xf + H_{t-1}·W_hf + b_f)   遗忘门(forget gate): 旧账本留多少
  O_t = σ(X_t·W_xo + H_{t-1}·W_ho + b_o)   输出门(output gate): 账本对外读多少
  C̃_t = tanh(X_t·W_xc + H_{t-1}·W_hc + b_c) 候选记忆元(candidate memory cell)
  C_t = F_t ⊙ C_{t-1} + I_t ⊙ C̃_t          记忆线更新（长期账本）
  H_t = O_t ⊙ tanh(C_t)                     输出线（值域锁 (-1,1)）
  ```
- 与 GRU 同构：C_t = F_t⊙C_{t-1} + I_t⊙C̃_t 对应 H_t = Z_t⊙H_{t-1} + (1-Z_t)⊙H̃_t（F↔Z, I↔1-Z）；GRU 一门管两头，LSTM 两门独立可调
- 梯度路径：遗忘门≈1 时 ∂C_t/∂C_{t-1} ≈ 1 → 梯度沿记忆线直通（输出线仍经 tanh，但梯度主走记忆线）
