## §3.x 线性回归 & Softmax

### [3.1~3.2] 训练循环四步走
- 困惑：前向 → 算损失 → backward → 更新，每一步在干什么？
- 核心：
  ```
  ① 前向：    y_pred = X@W + b          ← 用当前参数做预测
  ② 算损失：  loss = (y_pred - y)^2      ← 预测和正确答案差多少
  ③ 反向：    loss.backward()            ← 框架自动算每个参数的梯度
  ④ 更新：    param -= lr * param.grad   ← 沿着梯度方向调参数
  ```

### [3.4] Softmax + 交叉熵损失
- 困惑：为什么分类不用平方误差，要用交叉熵？
- 核心：
  ```
  平方误差：关注所有类的分数都接近正确答案 → 对「接近 0 但不够高」的类也要惩罚 → 梯度小，学得慢
  交叉熵：只关注「正确答案的概率」→ log(p) 在 p 接近 0 时梯度巨大 → 学得快
  一句话：分类任务用交叉熵，回归任务用 MSE
  ```

### [3.5] 交叉熵数学
- 困惑：-∑ y·log(p) 这个公式在做什么？
- 核心：y 是 one-hot（正确类=1，其余=0），所以公式简化为 -log(p_正确类)
  ```
  正确类概率 0.9 → -log(0.9) ≈ 0.1  ← 小损失 ✓
  正确类概率 0.1 → -log(0.1) ≈ 2.3  ← 大损失，惩罚狠
  ```

## §4.1 MLP 概念

### [4.1] 为什么要非线性激活函数？
- 困惑：两层 Linear 叠两层 Linear，跟一层有什么区别？
- 核心：
  ```
  没有激活函数：y = (X@W1+b1)@W2+b2 = X@(W1@W2) + (b1@W2+b2) = 一层线性 → 废物
  有 ReLU：     负数砍掉 → 线性变换被打断 → 真正的非线性 → 能学复杂边界
  面试官类比：
    线性 = 只看加权总分
    非线性 = 每个维度独立评判，某个方面不及格直接一票否决
  ```

### [4.2] MLP 参数维度
- 困惑：W1 到底是 (784, 256) 还是 (256, 784)？
- 核心：
  ```
  记住：W 的形状 = (这一层的输入数, 这一层的输出数)
  输入 784 → 隐藏层 256  →  W1 = (784, 256)
  隐藏层 256 → 输出 10   →  W2 = (256, 10)
  验证：X(batch, 784) @ W1(784, 256) → (batch, 256) ✓
  ```

### [4.5] 正则化
- 困惑：这个专业名词忘了是什么意思
- 核心：防止过拟合的「工具包」
  ```
  权重衰减：loss += λ||w||²        ← 权重太大扣分
  Dropout：训练时随机丢神经元      ← 没人可依赖，每个神经元学更扎实
  简化模型：少几层/少几个神经元    ← 不够复杂就没法死记硬背
  加数据：n_train 变大             ← 覆盖更多真实分布
  ```

### [4.6] Dropout 缩放
- 困惑：为什么训练时 dropout 后要除以 (1-p)？
- 核心：
  ```
  训练时随机丢 p% 神经元 → 期望输出 = (1-p) × 全量输出
  测试时不丢 → 输出会变大 1/(1-p) 倍 → 所以训练时提前缩放到期望一致
  不是测试时「加回来」，是训练时提前除好了
  ```

## §6.2 卷积

### [6.2] 卷积核的工作方式
- 困惑（纠正过）：以为卷积是先预处理定位再识别，两阶段
- 核心：
  ```
  错误理解：卷积找区域 → 全连接层识别（两阶段）
  正确理解：卷积+全连接 = 端到端一次训练，所有参数一起反向传播更新
  卷积核不是手设计的，跟全连接层权重一样是学出来的
  ```

## §6.3 填充和步幅

### 两个矛盾
- 卷积一次图片小一圈 → 填充 padding 补 0 保尺寸
- 步幅 1 太密，计算高度重叠 → 步幅 stride 隔步算

### 补 0 为什么好
0 在数学上是"中性元素" —— `0 × w = 0`，不会给卷积结果带额外激活。镜像/常数补法都会引入虚假信息。

### 奇数核偏好
`p = (k-1)/2` 奇数核 → 对称填充 → 输出中心对齐输入中心。
偶数核 → 不对称填充 → 输出偏移半个像素。

### 输出尺寸公式
`输出 = ⌊(n + 2p - k + s) / s⌋` 或者说 `⌊(n + 2p - k) / s⌋ + 1`

核心记忆：**填充保尺寸（p = (k-1)/2），步幅控尺寸（s=1 不变，s=2 减半）。公式记住最后 +1。**

## §6.4 多输入多输出通道

### 多输入通道
彩色图 RGB 3 通道 → 每个通道配一个不同的核 → 各自点积后**逐元素相加** → 单通道输出。
`一个核的参数 = C_in × k_h × k_w + 1(bias)`

### 多输出通道
每多一个卷积核，输出就多一个通道。
`C_out 个核 → C_out 个特征热力图`

| 名称 | 形状 | 含义 |
|:-----|:-----|:-----|
| 输入 | (N, C_in, H, W) | 批量×输入通道×高×宽 |
| 卷积核组 | (C_out, C_in, k_h, k_w) | 输出通道×输入通道×核高×核宽 |
| 输出 | (N, C_out, H', W') | 批量×输出通道×出高×出宽 |

### 参数计算 vs 全连接
```
Conv2d(3, 6, 3): 参数 = 6×(3×3×3+1) = 168
全连接处理 3×32×32→6×30×30: 参数 ≈ 3072×5400 ≈ 1659万
差了十万倍。
```

### 通道数直觉
```
RGB 3通道          → 简单颜色信息
↓ Conv (6 核)
6 通道              → 水平/垂直边缘/色块/纹理
↓ Conv (16 核)
16 通道             → 眼睛/嘴巴/轮子等形状
↓ Conv (32 核)
32 通道             → 人脸/汽车/建筑等语义概念
```
通道数越深，特征越抽象。

## §6.5 池化层

### 为什么需要池化
- 卷积对像素位置极其敏感——输入平移一点，输出完全不同
- 参数多，计算量大
- 池化（pooling）提供**平移不变性**：不管特征在哪个位置出现，都能检测到

### 最大池化 vs 平均池化
| 类型 | 做法 | 特性 |
|:-----|:-----|:-----|
| 最大池化（MaxPooling） | 窗口内取最大值 | 保留最强响应、丢弃噪声 |
| 平均池化（AvgPooling） | 窗口内取平均 | 保留整体响应强度 |

### §6.6 LeNet (1998)
- CNN 祖师爷，手写数字识别（MNIST）
- 架构骨架：Conv → Pool → Conv → Pool → 展平 → FC → FC → Output
- 现代改进：Sigmoid → ReLU，AvgPool → MaxPool

| | LeNet | 现代改进 |
|:---|:------|:---------|
| 激活函数 | Sigmoid | ReLU（不饱和，训练快） |
| 池化 | AvgPool（平均池化） | MaxPool（最大池化，保留最强） |
| 深度 | 2 Conv + 3 FC | 几十到上百层（ResNet） |

- 无填充：作者算好了尺寸链 32→28→14→10→5，每层自然缩小

## §7.x 现代卷积神经网络（部分）

### §7.1 AlexNet (2012)
- 卷积网络真正意义的开山之作
- 比 LeNet 更深更大：5 卷积层 + 3 全连接层
- 用 ReLU 替代 sigmoid（梯度不饱和，训练更快）
- 用 Dropout 防止过拟合
- 用 最大池化 + 小步幅保留信息

### §7.2 VGG (2014)
- **核心贡献：发现堆叠小核(3×3)比用大核(5×5/7×7)更好**
- 两个 3×3 堆叠 = 5×5 感受野，但参数更少，非线性更强
- VGG 块 = 连续 N 个 3×3 Conv + 1 个 2×2 MaxPool
- 缺点：参数太多（VGG16 有 1.38 亿参数）

### §7.3 NiN (Network in Network)
- 核心创新：用 1×1 卷积 + 全局平均池化 替代全连接层
- 1×1 卷积 = 跨通道的特征组合器（不改变空间尺寸，只改变通道数）
- 全局平均池化 = 每个通道输出一个平均值，直接分类

### §7.4 GoogLeNet / Inception (2014)
- 核心：Inception 块 — 同一个输入并行跑 4 条不同尺度的卷积，然后通道拼接
- 1×1 / 3×3 / 5×5 并行 + 3×3 最大池化，各抓各的特征
- 先用 1×1 降维再算大核（减少计算量）
- 9 个 Inception 块堆起来

### §7.5 批量归一化 (Batch Normalization, BN)
- **问题**：深层网络每层输入的分布一直在变（内部协变量偏移），下层参数的更新会改变上一层的输入分布，上层网络要不停适应下层的变化 → 训练困难
- **做法**：每层输出做归一化（减均值除标准差）+ 可学习的缩放/平移
- **好处**：可以用更大的学习率、减少对初始化的依赖、轻微正则化效果
- **公式**: `BN(x) = γ · (x - μ_B) / √(σ_B² + ε) + β` — γ(缩放)和β(偏移)是可学习参数

### §7.6 ResNet (残差网络, 2015)
- **核心问题**：网络越深不一定越好，56 层比 20 层训练误差和测试误差都更大（退化问题，不是过拟合）
- **核心创新**：残差连接（跳跃连接）
- **想法**：让网络去学"残差"而不是学"完整映射"
  - 普通块：`输出 = F(x)`（学完整映射）
  - 残差块：`输出 = F(x) + x`（学"还需要调整多少"）
- **直觉**：如果恒等映射是最优解，残差块只需要把 F(x) 学到 0，比普通块学整个恒等映射容易得多
- 残差块的关键：输入 x 通过跳跃连接直接加到输出，梯度有一条"高速公路"直达底层 → 可以训练 152 层甚至 1000+ 层

### 现代 CNN 架构演化

| 网络 | 核心创新 | 层数 | 关键参数 |
|:-----|:--------|:----|:--------|
| AlexNet | ReLU, Dropout, GPU 训练 | 8 | ~60M |
| VGG | 小核堆叠 | 16/19 | ~138M |
| NiN | 1×1 卷积, 全局平均池化 | — | — |
| GoogLeNet | Inception 多尺度并行 | 22 | ~5M（更少参数！）|
| ResNet | 残差连接 | 18/34/50/101/152 | ~25M |

## §10 注意力机制 (Attention)

### 为什么需要注意力？
- CNN 感受野有限，长距离依赖靠堆层数堆出来
- 注意力机制：**每个位置可以直接关注所有其他位置**

### 核心公式
```
Attention(Q, K, V) = softmax(Q × K^T / √d_k) × V

Q = Query（查询）：当前要关注什么特征
K = Key（键）：序列中所有位置的特征标签
V = Value（值）：序列中所有位置的实际内容
```

### 自注意力 — 每个词看其他所有词

```
输入序列 "我 喜欢 猫"
  我：看"我"时，跟"猫"的注意力权重最高
  喜欢：跟"我"和"猫"都有连接（主语和宾语）
  猫：看"猫"时，跟"喜欢"的权重最高
  
  结果：每个词都编码了它在句子中的上下文关系
```

### 多头注意力
- 一组 QKV 只能学一种"关注方式"
- 8 组并行的 QKV = 8 种不同的关注视角（语法/语义/位置...）
- 输出拼接后投影回到原始维度

### Transformer — 注意力的集大成者
```
输入 → 自注意力(多头) → 残差+层归一化 → 前馈网络 → 残差+层归一化 → 输出
                                          ↑
                                      这个循环堆 N 层
```

- **位置编码**：自注意力没有位置概念，用 sin/cos 函数给每个位置编码
- **解码器的自注意力**：只允许看到当前位置之前的词（掩码自注意力，也叫因果注意力）
- **编码器-解码器注意力**：解码器的 Query 看编码器的 Key-Value（翻译任务的关键）

### 注意力 vs CNN vs RNN

| 特性 | CNN | RNN | 自注意力 |
|:-----|:----|:----|:--------|
| 长距离依赖 | ❌ 靠堆层 | 🟡 梯度消失 | ✅ 直接连接 |
| 并行计算 | ✅ | ❌ 串行 | ✅ |
| 位置敏感 | ✅（卷积自带） | ✅（顺序输入） | ❌ 需要位置编码 |
