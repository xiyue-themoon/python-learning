# d2l §7.1 AlexNet 学习注释版

> 定位：深度学习开山之作。LeNet 放大 10 倍 + ReLU + Dropout + 大图数据 + GPU。
> 一句话：它证明了「学习到的特征 > 手工设计的特征」。

========================================
一、完整代码（PyTorch 教材版）+ 逐行注释
========================================

from d2l import torch as d2l
import torch
from torch import nn

net = nn.Sequential(
    # ===== 卷积阶段：负责特征提取 =====

    # Conv1: 输入 1 通道（灰度图），输出 96 通道
    # 11×11 大核：ImageNet 图大(224×224)，需要大视野看整体形状
    # stride=4 大步幅：快速缩小尺寸，省计算
    # padding=1：边缘不丢信息
    nn.Conv2d(1, 96, kernel_size=11, stride=4, padding=1),
    nn.ReLU(),          # 激活函数：负数砍 0，正数保留
    # 输出形状: 224×224×1 → 54×54×96
    # 公式: ⌊(224+2-11)/4⌋+1 = 54

    nn.MaxPool2d(kernel_size=3, stride=2),
    # 最大池化: 3×3 窗口取最大，步幅 2 → 尺寸减半
    # 54×54×96 → 26×26×96   (只缩尺寸，不动通道)

    # Conv2: 96 → 256 通道
    # 5×5 核 + padding=2 → 尺寸不变(26×26)，只翻通道
    nn.Conv2d(96, 256, kernel_size=5, padding=2),
    nn.ReLU(),
    # 26×26×96 → 26×26×256

    nn.MaxPool2d(kernel_size=3, stride=2),
    # 26×26×256 → 12×12×256

    # Conv3/4/5: 连续三个 3×3 卷积，中间不插池化
    # 目的：保持 12×12 分辨率，深挖中层特征
    # 三个 3×3 堆叠 = 7×7 感受野，但参数更少、非线性更强
    nn.Conv2d(256, 384, kernel_size=3, padding=1),
    nn.ReLU(),
    # 12×12×256 → 12×12×384  (通道先增)

    nn.Conv2d(384, 384, kernel_size=3, padding=1),
    nn.ReLU(),
    # 12×12×384 → 12×12×384  (保持不变)

    nn.Conv2d(384, 256, kernel_size=3, padding=1),
    nn.ReLU(),
    # 12×12×384 → 12×12×256  (通道再减)

    nn.MaxPool2d(kernel_size=3, stride=2),
    # 12×12×256 → 5×5×256

    # ===== 分类阶段：展平 + 全连接 =====

    nn.Flatten(),
    # 5×5×256 → 6400 维向量 (5×5×256=6400)

    nn.Linear(6400, 4096),
    nn.ReLU(),
    nn.Dropout(p=0.5),
    # 全连接层: 6400 → 4096
    # 参数大头在这里！6400×4096 ≈ 2622 万参数
    # Dropout 0.5: 训练时随机丢一半神经元，防过拟合
    # 只加在 FC 层，因为参数 92% 都在 FC

    nn.Linear(4096, 4096),
    nn.ReLU(),
    nn.Dropout(p=0.5),
    # 4096 → 4096，又一个巨型 FC，再 Dropout

    nn.Linear(4096, 10)
    # 4096 → 10 类输出 (Fashion-MNIST 是 10 类)
    # 论文原版是 1000 类 (ImageNet)
)

========================================
二、数字链（每层输出形状变化）
========================================

输入 224×224×1
  Conv1 (11×11, s4)  → 54×54×96     尺寸大缩，通道暴涨
  MaxPool            → 26×26×96     尺寸减半
  Conv2 (5×5, p2)    → 26×26×256    尺寸不变，通道翻倍
  MaxPool            → 12×12×256    尺寸减半
  Conv3 (3×3)        → 12×12×384    只翻通道
  Conv4 (3×3)        → 12×12×384    只翻通道
  Conv5 (3×3)        → 12×12×256    通道减少
  MaxPool            → 5×5×256      尺寸减半
  Flatten            → 6400
  FC1 (Dropout)      → 4096
  FC2 (Dropout)      → 4096
  FC3                → 10

规律：
- 卷积层：尺寸不变或缩小，通道逐渐增加（提取特征）
- 池化层：只管把尺寸减半（降分辨率）
- 全连接层：把特征向量映射到类别（分类）

========================================
三、三个核心 WHY
========================================

WHY 1: ReLU 为什么救活了深层网络？
- Sigmoid 梯度: σ'(z)=σ(z)(1-σ(z))，z 跑到 ±5 时梯度≈0
  → 8 层网络梯度传 3 层就没了 → 梯度消失
- ReLU 梯度: z>0 恒为 1，多深都不衰减 → 训练稳

WHY 2: 第一层为什么 11×11 大核 + stride 4？
- ImageNet 图 224×224，比 MNIST 大 10 倍
- 大核 = 一次看 121 像素，抓整体形状
- stride 4 = 快速降采样，否则计算量爆炸

WHY 3: 为什么连续三个 3×3 不插池化？
- 三 个 3×3 堆叠 = 7×7 感受野
- 参数: 3×(9C²)=27C² vs 大核 7×7: 49C² → 省 45%
- 还多了两层 ReLU 非线性 → 表达力更强

========================================
四、参数分布（震撼事实）
========================================

卷积层 5 个:  ≈ 372 万参数  (8%)
FC 层 3 个:   ≈ 4304 万参数 (92%)
总计:         ≈ 4670 万

为什么 FC 这么能吃参数？
- FC 全连接: 每个输入 × 每个输出都要一个权重
- 6400×4096 = 2622 万个权重，一个 FC 顶所有卷积层
- 这也是后面 NiN/GoogLeNet 要干掉 FC 的原因

========================================
五、术语对照表
========================================

- AlexNet = Alex 网络（作者 Alex Krizhevsky）
- ReLU = 线性整流单元（激活函数，负数砍0）
- Sigmoid = S 型函数（旧激活函数，梯度会消失）
- Dropout = 暂退法（随机丢神经元防过拟合）
- MaxPool = 最大池化（窗口取最大，降分辨率）
- Stride = 步幅（卷积核每次滑多远）
- Padding = 填充（边缘补 0 保尺寸）
- Flatten = 展平（多维张量拉成一维）
- FC = 全连接层（Fully Connected）
- 感受野 = 一个神经元能看到输入图多大区域

一句话记住

AlexNet = 老配方（卷积+池化+全连接）放大 10 倍
        + ReLU 解决梯度消失
        + Dropout 对付 92% 参数在 FC 的过拟合
        + 大图数据 + GPU 算力到位
它证明了「规模本身就是一种能力」。
